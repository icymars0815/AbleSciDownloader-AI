# 1.5.1 独立书目门槛验证

## 问题及最终流程

旧流程仅在科研通返回 undefined 空识别结果时调用 Crossref/PubMed。普通发布缺少统一的独立核实；明确“未找到”的弹窗还会提前停下，不能进入已有兜底。

现在所有科研通自动发布必须先通过独立 Crossref/PubMed 查询。对照导入时保留的原始 DOI、标题和已提供的作者，不用 AI 给出的“通过”标记或自动补全后的标题作为证据。至少一个来源匹配、没有已发现的记录冲突才允许继续。标题默认 90% 外另核对数字、菌株编号及否定词；作者支持姓名顺序、缩写和 et al. 的格式差异。

```text
原始引用
  → Crossref / PubMed 独立核实
  → 科研通 DOI 提取
      ├─ 已识别：对照权威标题
      └─ 未找到 / 未收录 / undefined：再次独立核实
            → 核实成功：按登记记录填 DOI、标题、链接、类型及来源等
            → 未核实：保留证据并停止
  → 表单回读 → 积分授权与最低悬赏检查 → 发布
```

书籍/章节可由 Crossref 确认，不强制要求 PubMed 收录；按相应登记类型填写。网络错误、查询失败和账户限制不归为未收录。没有唯一安全的关闭弹窗入口时不继续填表。费用保护沿用原规则，证明存在不构成花积分授权。

`kytdl check <DOI或条目ID> [--title-file <原始标题文件>] --json` 只读查询、不入队、不填表、不花分。已有条目始终读取原始引用，正式发布时仍独立重查。`result.reference_check` 保留来源、状态和核查原因；书目阻断显示 `reference_review`。

## 本地正反例

新增 `tests/test_reference_gate.py`，25 项定向测试通过，全部使用临时数据、虚构书目、模拟公共 API 和脚本化页面。

- 正例：Crossref 单独确认、PubMed 单独确认、正常期刊发布、DOI-only 存在性、完整引用、作者缩写和 et al.、标题 HTML 格式、书籍与章节兜底。
- 反例：虚构/未命中 DOI、真实 DOI 搭配错误标题、作者错误、原始 DOI 被替换、自动补全掩盖原始标题、伪造通过标记、关键数字/菌株/否定词差异、两个来源冲突、API 故障或无效响应。
- 兜底：二次核查失败不填表；没有唯一关闭入口不填表；书籍最低积分高于授权不提交；网络查询失败和账户限制不进入未收录兜底。
- CLI：能检查原始引用，默认不改队列、不导入、不发布；通过退出 0，未核实退出 4。

原有发布、额度、导入及流水线相关的 190 项定向回归通过。最终全量回归命令 `.venv\Scripts\python.exe -m unittest discover -s tests`：937 项，170.549 秒，OK（5 skipped，抽象测试基类），无失败。安装自检、服务重启及无需 site-packages 的离线版本命令通过。

## 在线只读验证 — 2026-11-11

通过真实服务的 CLI 调用公共 Crossref/PubMed API，未向科研通发布新求助。

| 样例 | 预期 | 实际 |
|---|---|---|
| 真实论文 DOI 与原始标题 | 通过 | Crossref 和 PubMed 匹配 |
| 真实章节 DOI 与原始标题 | 通过 | Crossref 匹配，PubMed 未命中仍可通过 |
| 真实 DOI 与虚构标题 | 拦截 | mismatch |
| 同一篇标题中的 FRT7 改为 FRT8 | 拦截 | mismatch |
| 明确构造的虚构 DOI | 暂不允许发布 | not_found |

5/5 符合预期。另复用了上轮同一篇最低悬赏 80 分的候选，仍仅确认 10 分：新版服务记录 Crossref 和 PubMed 核实通过，进入真实科研通 DOI 查询后仍以 `min_reward_raised` 阻断，未发布、未加价。没有新增候选，新增积分消耗为 0。上述在线检查证明公开 API、CLI 核查和实站前置核实/费用保护衔接可用；科研通未收录时的完整填表及提交分支使用模拟页面验证，本轮未新增真实付费求助，不将模拟当作真实网站提交成功。

## 边界

- `not_found` 仅是所查询来源本次未命中；`unavailable` 是未知；都不证明文献不存在。Crossref/PubMed 的覆盖不代表所有出版物。
- 仅给 DOI 时只验证对应登记记录存在，无法判断 AI 在其他地方描述过但没有提交给软件的标题、作者或年份。AI 应保留原始引用字段。
- 当前自动流程仍要求 DOI；无 DOI 的书籍需核实出版社、ISBN/馆藏目录后人工求助，不编造 DOI、不自动降级放行。
- 本门槛不认证论文研究结论、全文完整性或全部出版细节；后续 PDF/MD 审核、版本和撤稿检查继续适用。
- 对证据冲突保守停下可能增加人工核查，但不能为了通过而自动替换原引用。只读 check 不自动恢复已阻断的队列，恢复后仍重查并遵守原积分授权。
